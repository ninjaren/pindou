# 拼豆圖工具 v0.7

把任意圖片（照片、插圖、卡通圖）自動轉換成拼豆排列圖，並列出每個顏色需要幾顆，方便直接採購與製作。
※本工具由ChatGPT及Claude參與協做。

---

## 功能總覽

- **圖片轉拼豆圖**：縮圖到指定格數，映射到 67 色拼豆色盤
- **背景去除**：支援去除黑底或白底（BFS 氾水填充）
- **預先量化減色**：Median Cut 減色 + Median Filter 平滑，讓色塊更穩定、不亂跳
- **雜點消除**：孤立格子自動替換成周圍多數色
- **相似色合併**：可調整門檻，把用量少的近似色合併，減少實際需採購的顏色種數
- **放大預覽**：顯示格線 / 顏色編號，方便對著圖排豆
- **匯出**：儲存預覽圖（PNG）、匯出顏色採購清單（CSV）
- **拖放載入**：支援直接把圖片拖進視窗（需 tkinterdnd2）

## 系統需求

- Python 3.10+
- 套件：`Pillow`、`tkinterdnd2`（選用，無此套件仍可執行，只是不支援拖放）

安裝套件：

```bash
pip install pillow tkinterdnd2
```

## 使用流程

1. **載入圖片**：點「載入圖片」按鈕，或直接將圖片拖入視窗
2. **調整參數**：
   - **格數**：橫向格數（預設 52，即 52×52 拼豆板）
   - **去除背景**：黑底 / 白底 / 不去除
   - **量化色數**：預先減色數量（預設 12）
   - **相似色合併門檻**：0 = 不合併，越大合併越激進
3. **產生拼豆圖**：點「產生拼豆圖」，右側顯示放大預覽，下方列出顏色統計
4. **匯出**：
   - 「儲存拼豆圖」→ 存 PNG
   - 「匯出 CSV」→ 存顏色採購清單（含編號、顏色名稱、RGB、顆數）

## 色盤說明

色盤定義在 [`palette_data.py`](palette_data.py)，共 67 色，涵蓋插畫與卡通常用色系：

| 色系 | 顏色數 |
|------|--------|
| 中性色（白～黑） | 9 色 |
| 紅色系 | 11 色 |
| 橘 / 膚色系 | 9 色 |
| 黃色系 | 6 色 |
| 綠色系 | 8 色 |
| 藍色系 | 8 色 |
| 紫色系 | 8 色 |
| 棕色系 | 8 色 |

**換品牌只需修改 `palette_data.py`**，程式主體不用動。

## 核心算法

### 顏色匹配：Redmean 加權 RGB 距離

比普通歐式距離更符合人眼視覺感知：

```
距離 = sqrt((2 + r̄/256)·ΔR² + 4·ΔG² + (2 + (255-r̄)/256)·ΔB²)
```

其中 `r̄` 為兩色 R 通道的平均值。

### 圖片處理管線

```
原圖
  │
  ▼
縮圖到格數大小（可選保持比例）
  │
  ▼
去除背景（BFS 氾水填充，可選）
  │
  ▼
Median Cut 預先量化減色（穩定色塊，可選）
  │
  ▼
Median Filter 平滑色塊邊緣（修復鋸齒中間色）
  │
  ▼
逐格映射到拼豆色盤
  │
  ▼
雜點消除（孤立格子替換，可選）
  │
  ▼
拼豆圖 + 顏色統計
```

## 檔案結構

```
pindou/
├── main.py                   # 程式進入點
├── beads_gui_pretty.py       # 主 GUI（Tkinter，v0.7）
├── beads_logic.py            # 核心算法（圖片處理、顏色映射）
├── palette_data.py           # 67 色拼豆色盤資料
├── preview_utils.py          # 放大預覽圖產生
├── export_utils.py           # 圖片儲存 / CSV 匯出
├── pindou_v0.7.spec          # PyInstaller 打包設定
└── dist/
    └── pindou_v0.7.exe       # 打包好的 Windows 執行檔
```

## CSV 匯出格式

| 欄位 | 說明 |
|------|------|
| 編號 | 顏色序號（按用量由多到少排列） |
| 顏色名稱 | 中文顏色名稱 |
| R / G / B | 色盤 RGB 值（供比對） |
| 數量 | 該顏色需要的顆數 |
